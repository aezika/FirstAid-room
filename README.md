# 🏥 ระบบจัดการใช้บริการห้องพยาบาลของบริษัท

แอปพลิเคชัน Flask (single-file) สำหรับจัดการการขอใช้บริการห้องพยาบาลของพนักงานในบริษัท ตั้งแต่ยื่นคำขอ อนุมัติโดยหัวหน้างาน พยาบาลวินิจฉัยและจ่ายยา ไปจนถึงรายงานวิเคราะห์การเจ็บป่วยประจำเดือน

---

## คุณสมบัติ

- **พนักงาน** — บันทึก/ดูรายละเอียดพนักงาน (รหัส, ชื่อ-นามสกุล, แผนก, ตำแหน่ง, เบอร์โทร)
- **คำขอใช้บริการ** — พนักงานกรอกอาการเบื้องต้นเพื่อขอใช้บริการห้องพยาบาล
- **อนุมัติโดยหัวหน้างาน** — อนุมัติ หรือไม่อนุมัติ พร้อมระบุเหตุผล
- **งานพยาบาล** — พยาบาลประจำบันทึกผลวินิจฉัย กลุ่มโรค คำแนะนำการรักษา และจ่ายยา
- **คลังยา (Stock)** — จัดการรายการยา จำนวนคงเหลือ สต็อกขั้นต่ำ และเติมสต็อก พร้อมตัดสต็อกอัตโนมัติเมื่อจ่ายยา
- **รายงานประจำเดือน** — วิเคราะห์ตามเดือนที่เลือก: จำนวนครั้งที่เข้ารับบริการ, กลุ่มโรคที่พบบ่อย, ความถี่ของแต่ละกลุ่มโรค (กราฟวงกลม), ความถี่การจ่ายยาแต่ละชนิด (กราฟแท่ง)

---

## ความต้องการของระบบ

- Python 3.9 ขึ้นไป
- แพ็กเกจ `Flask`

---

## วิธีติดตั้งและรัน

1. ติดตั้ง Flask (ครั้งแรกครั้งเดียว):

   ```bash
   pip install flask
   ```

2. รันแอป:

   ```bash
   python app.py
   ```

3. เปิดเบราว์เซอร์ไปที่:

   ```
   http://localhost:5000
   ```

เมื่อรันครั้งแรก ระบบจะสร้างไฟล์ฐานข้อมูล `clinic.db` (SQLite) ในโฟลเดอร์เดียวกันโดยอัตโนมัติ พร้อมข้อมูลตัวอย่าง (พนักงาน 3 คน และรายการยาเริ่มต้น 7 รายการ) ให้ทดลองใช้งานได้ทันที

> หากต้องการล้างข้อมูลทั้งหมดและเริ่มใหม่ ให้ปิดแอปแล้วลบไฟล์ `clinic.db` จากนั้นรัน `python app.py` ใหม่อีกครั้ง

## ขั้นตอนการใช้งาน (Workflow)

1. **เพิ่มพนักงาน** — เมนู "พนักงาน" → กรอกฟอร์มด้านซ้าย เพื่อเพิ่มพนักงานเข้าระบบ (มีข้อมูลตัวอย่างให้แล้ว)
2. **ยื่นคำขอใช้บริการ** — เมนู "คำขอใช้บริการ" → กด "+ ยื่นคำขอใหม่" → เลือกพนักงาน กรอกอาการเบื้องต้น → ส่งคำขอ (สถานะ: *รออนุมัติ*)
3. **หัวหน้างานอนุมัติ** — ที่หน้า "คำขอใช้บริการ" กดปุ่ม **อนุมัติ** หรือ **ไม่อนุมัติ** (พร้อมระบุเหตุผลถ้าไม่อนุมัติ) ในแถวของคำขอนั้น
4. **พยาบาลบันทึกการตรวจรักษา** — เมนู "งานพยาบาล" จะแสดงคิวคำขอที่อนุมัติแล้ว กด **บันทึกตรวจรักษา** เพื่อกรอก:
   - ชื่อพยาบาลผู้ตรวจ
   - กลุ่มโรค / ผลวินิจฉัย / คำแนะนำการรักษา
   - รายการยาที่จ่าย (เลือกยาและจำนวน — กด "+ เพิ่มรายการยา" เพื่อเพิ่มได้หลายรายการ) ระบบจะ**ตัดสต็อกยาอัตโนมัติ**และตรวจสอบว่ายาคงเหลือเพียงพอก่อนบันทึกเสมอ
   - เมื่อบันทึกแล้ว สถานะคำขอจะเปลี่ยนเป็น *เสร็จสิ้น*
5. **จัดการคลังยา** — เมนู "คลังยา" ใช้เพิ่มรายการยาใหม่ หรือเติมสต็อกยาที่มีอยู่ ระบบจะไฮไลต์สีแดงเมื่อยาคงเหลือต่ำกว่าหรือเท่ากับสต็อกขั้นต่ำที่ตั้งไว้
6. **ดูรายงานประจำเดือน** — เมนู "รายงานประจำเดือน" เลือกเดือนที่ต้องการ ระบบจะสรุป:
   - จำนวนครั้งที่เข้ารับบริการ และจำนวนพนักงานที่มาใช้บริการ (ไม่ซ้ำ)
   - กลุ่มโรคที่พบมากที่สุด และยาที่จ่ายมากที่สุด
   - กราฟวงกลมความถี่ของกลุ่มโรค และกราฟแท่งความถี่การจ่ายยา พร้อมตารางสรุป

## โครงสร้างข้อมูล (SQLite)

| ตาราง | ใช้เก็บ |
|---|---|
| `employees` | รายละเอียดพนักงาน |
| `requests` | คำขอใช้บริการและสถานะการอนุมัติ |
| `visits` | ผลการตรวจของพยาบาล (วินิจฉัย, กลุ่มโรค) ผูกกับคำขอ 1 รายการ |
| `medicines` | รายการยาและจำนวนคงเหลือในสต็อก |
| `dispenses` | รายการยาที่จ่ายในแต่ละครั้งที่ตรวจ (ผูกกับ `visits`) |

## หมายเหตุ

- โปรเจกต์นี้เป็น **prototype** ยังไม่มีระบบล็อกอิน/แยกสิทธิ์ผู้ใช้งาน — ทุกคนที่เข้าเว็บจะเห็นและใช้งานได้ทุกเมนู (เหมาะสำหรับสาธิต/ทดสอบภายใน)
- ใช้ Tailwind CSS และ Chart.js ผ่าน CDN จึงต้องมีการเชื่อมต่ออินเทอร์เน็ตขณะเปิดหน้าเว็บ (แต่ตัวแอปและฐานข้อมูลทำงานในเครื่อง/local ทั้งหมด)
- เซิร์ฟเวอร์ที่รันด้วย `python app.py` เป็น Flask dev server เหมาะสำหรับทดสอบ/ใช้งานภายในเท่านั้น หากต้องใช้งานจริงในองค์กร ควร deploy ด้วย WSGI server (เช่น gunicorn/waitress) และเพิ่มระบบยืนยันตัวตน
